# Start here (for the owner)

1. Create an empty GitHub repo, for example `desk-garden` (private is fine).
2. Clone it on your Windows laptop and open the folder in Claude Code.
3. Put desk-garden-handoff.zip in the repo folder and send Claude Code this prompt:

   Extract desk-garden-handoff.zip into this repo root so CLAUDE.md sits at the top level, then delete the zip. Read CLAUDE.md and build the Desk Garden v0.1 prototype exactly as described. Start with the smallest version that draws the base layer behind the desktop icons and restores the normal wallpaper on quit, show it to me, then add the scene, time of day, weather, cursor ripples, water basin, pause rules and tray menu step by step. Measure memory and CPU after each step and keep MEASUREMENTS.md up to date.

4. Test on your own desktop. If anything looks off (black desktop, icons hidden, wallpaper not restored), tell Claude Code exactly what you see. To recover manually: quit Desk Garden from the tray, or restart Windows Explorer in Task Manager.
